# FitCasino — демо-витрина слотов

Статический сайт (HTML/CSS/JS, без сборки и без бэкенда). Все данные
(аккаунты, баланс, история) хранятся в `localStorage` браузера —
это учебный/портфолио-проект на условные фишки, без реальных денег.

## Как выложить на GitHub Pages (с телефона)

1. Скачайте и распакуйте архив `fitcasino.zip`.
2. Зайдите в приложение **GitHub** (или сайт github.com в браузере телефона),
   создайте новый репозиторий, например `fitcasino`.
3. Загрузите в него все файлы из архива, сохранив структуру папок
   (`index.html`, `lobby.html`, `play.html` и т.д. — в корне репозитория,
   папки `css/` и `js/` — как есть).
4. В репозитории откройте **Settings → Pages**.
5. В разделе **Build and deployment** выберите **Source: Deploy from a branch**,
   ветку `main` и папку `/ (root)`. Сохраните.
6. Через 1–2 минуты сайт будет доступен по адресу вида
   `https://<ваш-логин>.github.io/fitcasino/`.

Дальнейшие правки можно вносить прямо в GitHub (кнопка карандаша у файла) —
пересборка не нужна, это чистый статический сайт.

## Что внутри

- `index.html` — вход/регистрация. **Первый зарегистрированный аккаунт
  на сайте автоматически получает права администратора.**
- `lobby.html` — витрина из 7 оригинальных слотов.
- `play.html` — экран игры: вращение, автоспины, покупка бонуса, фриспины.
- `profile.html` — баланс, статистика, история, пополнение демо-фишек.
- `rtp.html` — прозрачное описание математики и RTP.
- `admin.html` — админ-панель: список игроков и управление демо-балансом.
  RTP и вероятности символов зафиксированы в коде и не редактируются
  из админ-панели.

## Математика

Единая модель для всех слотов, подобранная и проверенная симуляцией
Монте-Карло на 500 000 вращений (см. `rtp_sim2.py`):

- Поле 5×3, 20 фиксированных линий выплат.
- Теоретический RTP ≈ 96.3%, частота выплат ≈ 41%.
- Wild заменяет любые символы кроме Scatter.
- Scatter (в любом месте поля): 3/4/5 символов → 10/15/20 фриспинов,
  плюс собственная выплата.
- Bonus Buy: мгновенный запуск фриспинов за ×12 от ставки — цена
  рассчитана так, чтобы RTP покупки был не выше базового RTP игры.
- «Каскад» в двух слотах (Sweet Rush, Dragon's Fortune) — визуальный
  эффект после выигрыша, не добавляет дополнительных выплат.

Полные исходники симулятора (`rtp_sim.py`, `rtp_sim2.py`) включены в архив
для проверки расчётов.

## Важно понимать перед использованием

- Это демонстрационный проект, не аттестованный продукт для игры на
  реальные деньги (нет лицензии, нет независимого RTP-аудита).
- Аутентификация — простая клиентская (localStorage), без сервера.
  Не используйте для этого реальные пароли, которые применяете где-то ещё.
- Все графические символы — оригинальные SVG-иконки, без сторонних
  изображений и без эмодзи.
